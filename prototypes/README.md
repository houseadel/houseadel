# Nexus prototypes

The working prototypes are isolated Phase 1 evidence, not the production House Adel homepage. Their route components live in `src/components/prototypes/`; these directories hold each prototype's required evidence record.

- [`svg-fracture/`](svg-fracture/) — semantic DOM/SVG fracture at `/prototypes/fracture`
- [`hybrid-glass/`](hybrid-glass/) — restrained WebGL glass at `/prototypes/hybrid`
- [`cinematic-compositing/`](cinematic-compositing/) — layered media and minimal real-time compositing at `/prototypes/cinematic`

Shared contracts are in `docs/prototype-briefs.md`; measured results and budgets are in `docs/performance-baseline.md`.

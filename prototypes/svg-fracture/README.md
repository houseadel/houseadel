# Prototype A — SVG / DOM fracture

## Purpose

Test whether a shattered or fragmented nexus can remain an editorial composition made from real links, without requiring WebGL to communicate the connected-realities idea.

## Reference basis

- the dual expressive/semantic paths observed in Bruno Simon and Unseen;
- direct indices retained by Studio Freight, Shopify Editions, and Obys;
- the semantic and interruption rules in `research/navigation-patterns.md` and `research/transition-patterns.md`.

This is a synthesis, not a visual copy of a reference.

## Technologies used

- semantic HTML navigation and images;
- CSS polygon clipping and responsive re-composition;
- GSAP for one bounded exit timeline;
- the native History API review router;
- responsive AVIF/WebP candidates from the shared asset manifest.

## Performance result

Production-preview desktop: 293 KiB encoded resources, 109 KiB route code gzip, 102 KiB imagery, 428 ms local LCP, 16.8 ms p95 frame cadence, no long tasks, and no WebGL/GPU allocation. Lighthouse mobile simulation: performance 95, accessibility 100, 2,508 ms LCP, 0 ms total blocking time.

## Mobile result

The three fragments become a vertical sequence instead of shrinking the desktop geometry. All titles remain visible, the same three links remain in reading order, and the canvas budget remains zero. Mobile emulation measured 388 ms local LCP and 16.8 ms p95 cadence.

## Strengths

- clearest semantic and keyboard contract;
- lowest code, media, GPU, and specialist burden;
- strongest no-WebGL and reduced-motion baseline;
- easiest universe addition through data plus one image family;
- the only candidate currently clearing all automated frame and long-task guardrails.

## Weaknesses

- literal fracture still risks superhero, impact-crack, or theme-selector associations;
- irregular titles and shapes need careful composition at every breakpoint;
- it offers less material depth than B and less image immersion than C;
- extraordinary results still depend on exceptional type and master frames.

## Recommendation

Keep A as the mandatory fallback and strongest production baseline. Select literal fracture as the main expression only if creative review finds the material conceptually appropriate; otherwise retain its semantic architecture beneath an optical or editorial composition.

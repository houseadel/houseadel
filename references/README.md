# References

Behavioural reference material only, per `AGENTS.md`: "References are behavioural only and never appear publicly." Nothing in this directory is copied — no reference assets, copy, code, layouts, shaders, marks, or distinctive compositions. What is studied here is how something behaves (pacing, structure, interaction), never how it looks.

Captured evidence (screenshots, recordings) is local working material and is not committed — see `references/captures/generated/` and `references/recordings/generated/` in `.gitignore`. Written analysis derived from that material lives in `research/`, including the per-studio dossiers in `research/reference-dossiers/`.
